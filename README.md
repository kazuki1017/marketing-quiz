# マーケティング小テスト演習

火2「マーケティング」小テスト（第1〜5回）の自習用ページです。`index.html` 1つで全部動きます。

- 4択53問：選ぶとすぐに正解・不正解と解説
- 穴埋め70か所：入力して「答え合わせ」で自動採点。解説つき
- 論述6問：キーワードが入っているかを自動チェック。解答例つき

## 使い方

`index.html` をダウンロードしてブラウザで開きます（ZIPで落とした場合も、`index.html` を開くだけで使えます）。上のメニューで「ホーム・4択・穴埋め・論述」を切り替えます。入力した答えと「前回まちがえた問題」はそのブラウザに保存されます。

## 注意

問題は個人の復習用に作ったもので、授業の公式な資料ではありません。
