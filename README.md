# マーケティング小テスト演習

火2「マーケティング」小テスト（第1〜5回）の自習用ページです。

- 穴埋め70か所：入力して「答え合わせ」で自動採点。解説つき
- 論述6問：キーワードが入っているかを自動チェック。解答例つき
- 4択53問（`choice.html`）：選ぶとその場で○✕と解説。まちがえた問題だけ解き直せる

## 使い方

`index.html`（穴埋め・論述）と `choice.html`（4択）をダウンロードしてブラウザで開くだけで使えます。2つを同じフォルダに置くと、ページ上のリンクで行き来できます。入力した答えはそのブラウザに保存されます。

Claudeによる論述の採点は、Claude上で開いたときだけ使えます。このページを単体で開いた場合は、ボタンが表示されません。
