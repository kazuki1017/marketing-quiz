# マーケティング小テスト演習

火2「マーケティング」小テスト（第1〜5回）の自習用ページです。

| ファイル | 中身 |
| --- | --- |
| `index.html` | ホーム。下の2つのページに進める |
| `dads.css` | 3ページ共通の見た目（デジタル庁デザインシステムを参考） |
| `fill.html` | 穴埋め70か所（自動採点・解説つき）と論述6問（キーワード確認・解答例つき） |
| `choice.html` | 4択53問。選ぶとその場で○✕と解説。まちがえた問題だけ解き直せる |

## 使い方

すべてのファイルを同じフォルダにダウンロードし、`index.html` をブラウザで開きます。ページ上のリンクで行き来できます。入力した答えと「前回まちがえた問題」はそのブラウザに保存されます。

Claudeによる論述の採点は、Claude上で開いたときだけ使えます。ダウンロードして開いた場合は、そのボタンは表示されません。
