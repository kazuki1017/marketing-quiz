# マーケティング小テスト演習

火2「マーケティング」小テスト（第1〜5回）の自習用ページです。

- 穴埋め70か所：入力して「答え合わせ」で自動採点。解説つき
- 論述6問：キーワードが入っているかを自動チェック。解答例つき

## 使い方

`index.html` をダウンロードしてブラウザで開くだけで使えます。入力した答えはそのブラウザに保存されます。

Claudeによる論述の採点は、Claude上で開いたときだけ使えます。このページを単体で開いた場合は、ボタンが表示されません。
